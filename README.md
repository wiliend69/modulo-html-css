#  Trayecto 1: Rueda Libre | Parche-Dev | IA Generativa


##  Descripción del Proyecto

**Rueda Libre** es un sitio web diseñado para promover el uso de la bicicleta como medio de transporte urbano. En esta **Versión 0.2**, el proyecto evoluciona incorporando:
* **Estructura Semántica Avanzada:** Uso correcto de etiquetas HTML5 (`header`, `nav`, `main`, `section`, `article`, `footer`).
* **Formulario Seguro y Validado:** Restricciones estrictas en el cliente para impedir el envío de datos incompletos, correos inválidos o formatos incorrectos.
* **Accesibilidad (WCAG):** Contraste de color optimizado, etiquetas asociadas correctamente y navegación lógica por teclado.
* **Bitácora y Documentación:** Registro detallado de pruebas de validación, auditoría de accesibilidad y mapa de uso de color.

---

##  Tecnologías y Estándares

* **HTML5:** Marcado semántico y validación nativa de formularios (`required`, `minlength`, `pattern`, `type="email"`).
* **CSS:** Diseño responsivo y aplicación de paleta de colores limpia y moderna.
* **Git y GitHub:** Control de versiones y despliegue continuo mediante GitHub Pages.
* **WCAG 2.1 (Nivel AA):** Criterios de accesibilidad web.
