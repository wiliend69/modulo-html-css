15 comando utilizados 
*pwd : esto lo utilice para ver en que archivo estaba ubicado
*ls: se utilizo para ver el el listado de las carpetas en la ruta
*ls -a: para ver las lista ocultas
*ls -l: para ver los detalles 
*cd .. :para devolverme entre carpetas
*cd ../../ : para desplazarme rapidamente a una carpeta a otra sin necesita de utilizar cd ..
*mkdir: lo utilice para crear carpetas
*mkdir -p: para crear una carpeta y sus subcarpetas
*touch: crear archivos no carpetas
*> : para escribir en un texto o sobrescribir en un txt 
*>> : para poner al final un texto 
*echo: para imprimir un escrito en un .txt
*cat: lo utilice para ver el texto en los .txt
*head: consultar las primeras lineas en un texto
*find: para buscar algun directorio o archivo
*find -type f: para buscar todos los archivos
*find -type d: para buscar todas las carpetas
